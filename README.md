# Titanic-Survival-Prediction
Use the Titanic dataset to build a model that predicts whether a passenger on the Titanic survived or not. 

This project uses the classic Titanic dataset from Kaggle to build a machine learning model that predicts whether a passenger survived the Titanic disaster. 

The dataset includes features such as age, gender, passenger class, fare paid, number of siblings/spouses aboard, and port of embarkation.

The data was cleaned by handling missing values and converting categorical variables (like sex and embarkation port) into numeric form using one-hot encoding. Feature selection focused on columns with the strongest predictive power, such as Sex, Pclass, and Fare.

 Visualization tools such as Seaborn were used to explore relationships between features and survival, particularly the strong correlation between gender/class and survival rate.
